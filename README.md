# React Movies App

Aplicação web desenvolvida com **React + TypeScript** para busca e navegação de filmes, com foco em experiência do usuário, componentização e boas práticas de desenvolvimento Front-end.

O projeto consome uma API externa de filmes e implementa funcionalidades modernas presentes em aplicações reais do mercado, como busca dinâmica, scroll infinito e skeleton loading.

---

## Tecnologias utilizadas

- React
- TypeScript
- React Router
- CSS Modules
- Git & GitHub

---

## ✨ Funcionalidades

- Consumo de API de filmes
- Busca dinâmica de filmes
- Debounce de busca
- Scroll infinito
- Componentização
- Custom Hooks
- Rotas dinâmicas
- useParams e useLocation
- Skeleton Loading
- Loading states
- Tratamento de erros
- Interface responsiva
- CSS Modules
- Dropdown Menu
- Versionamento com Git

---

## Conceitos trabalhados

Este projeto foi desenvolvido com foco em consolidar conhecimentos de Front-end moderno, incluindo:

- Componentização e reutilização de código
- Gerenciamento de estado
- Consumo de APIs REST
- Navegação entre páginas
- Manipulação de rotas
- Performance com debounce
- Organização escalável de projetos React
- Estruturação com TypeScript
- Experiência do usuário (UX)

## Como executar o projeto

```bash
# Clone o repositório
git clone https://github.com/gutosavi/react-movies-app

# Acesse a pasta
cd react-movies-app

# Instale as dependências
npm install

# Execute o projeto
npm run dev
```
